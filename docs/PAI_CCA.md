# CT-264 Programming for Artificial Intelligence

## Complex Computing Activity (CCA) through Problem Based Learning (PBL)

### Course Learning Outcome

**CLO 3 (C3):** Identify appropriate AI techniques to solve classification problems of moderate complexity.

### Complex Computing Activity Attributes

- **CA 2: Problem Analysis and Solution Development:** Students analyze the given AI problem, identify relevant inputs and outputs, evaluate alternative solution strategies, and develop an effective computational solution.
- **CA 3: Application of AI Knowledge:** Students demonstrate a thorough understanding of Artificial Intelligence concepts and apply appropriate algorithms and computing principles to implement accurate solutions and explain their practical applications.

---

## Project Description

The project should address a meaningful real-world problem using Python programming, data analysis, and AI techniques. Students may select any suitable application domain, such as healthcare, finance, education, retail, transportation, or environmental monitoring. Projects involving AI applications, chatbots, or simple intelligent assistants are also acceptable.

Students must clearly describe the selected problem, its objectives, real-world significance, and proposed solution. They may choose a suitable AI or deep learning approach according to the problem and available data. The implementation should remain manageable within the scope of an introductory Programming for AI course.

At least two relevant datasets or one sufficiently large and suitable dataset must be used. Students should briefly describe the data source, data types, important features, and relevance to the problem.

### Dataset Analysis and Implementation

- Perform data preprocessing to handle missing values and inconsistencies where necessary.
- Conduct meaningful Exploratory Data Analysis (EDA) using statistical summaries and visualizations to identify patterns and relationships.
- Check for class imbalance in classification problems and address it where necessary.
- Implement a suitable AI or deep learning model of the students' choice.
- Evaluate the model using appropriate performance metrics.
- If an external API is used, briefly explain its purpose and integration into the project.

### Assumptions & Constraints

- Projects must be completed in the designated groups.
- The selected problem must be feasible within the scope of an AI programming course.
- Emphasis should be placed on Python programming, data preprocessing, EDA, visualization, model implementation, and interpretation of results.
- Students may choose their own AI or deep learning approach, provided the implementation remains simple and manageable.
- Students must explain their code, visualizations, evaluation results, and conclusions.
- Data privacy and ethical considerations must be followed where applicable.
- The final project must demonstrate a working Python implementation and meaningful conclusions based on the data.

### Deliverables

- **Python Code Implementation:** Design a complete AI solution for a real-world problem using at least two datasets, including preprocessing, model building, evaluation, and performance improvement (e.g., tuning or ensembling).
- **Visualization:** Develop a simple, user-friendly visualization or interface to present results. This could include charts, maps or prediction outputs. The goal is to make the findings interpretable and actionable for users.
- **Technical Report:** Compile a minimum 10-page technical report covering methodology (with diagram), models used, results, and challenges.
